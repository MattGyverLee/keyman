# Evidence — moved

The run logs, CSVs, `rawinput-delivery.md`, `TRIAGE.md`, and the
follow-on issue drafts that used to live in this folder were
moved out of this PR in October 2026, because historical
run outputs for one machine are not reviewable, rerunnable
code, and they go stale on every rebase.

They are preserved, unaltered, in the evidence archive:

- Branch: `evidence/8064-16462` in MattGyverLee/keyman
- Folder: `keyman-evidence/16490-GH-8064/manual-tests-GH-8064/`
- Index: `keyman-evidence/README.md` on that branch

Do not re-add logs here. Rerun the script that produced a
log, on the SHA under test, and record the new result with
its date, branch, head SHA, and machine. A log in the
archive is history, not proof for a later build.
